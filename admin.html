So funktioniert's
  1. Fach wählen. Neues Foto? → „Foto ersetzen“ (wird hier im Browser verkleinert und verschlüsselt).
  2. Gerät in der Liste auswählen oder neu anlegen, dann auf dem Foto ein Rechteck um das Gerät ziehen.
  3. Rechteck antippen = auswählen, „Rechteck löschen“ entfernt es.
  4. Unten „Dateien herunterladen“ → auf GitHub unter data/ (Fotos nach data/img/) per Add file → Upload files hochladen.

Nur .enc-Dateien hochladen – nie die Original-Fotos.
